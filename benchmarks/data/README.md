# benchmarks/data

Captured inputs, checked in so that measurements reproduce without network
access.

## `mcp_tools.json`

`tools/list` output from seven published MCP servers, captured over stdio by
[`../mcp_probe.py`](../mcp_probe.py). Refresh it with:

```bash
python3 benchmarks/mcp_corpus.py --capture
```

| server | package |
| --- | --- |
| everything | `@modelcontextprotocol/server-everything` |
| filesystem | `@modelcontextprotocol/server-filesystem` |
| memory | `@modelcontextprotocol/server-memory` |
| sequential | `@modelcontextprotocol/server-sequential-thinking` |
| time | `mcp-server-time` |
| git | `mcp-server-git` |
| fetch | `mcp-server-fetch` |

## `mcp_results.json`

23 `tools/call` responses from six of the same servers, captured by
[`../mcp_output.py`](../mcp_output.py). Refresh with:

```bash
python3 benchmarks/mcp_output.py --capture
```

Every call is **read-only and local**. `fetch` is never called, because its only
tool reaches someone else's infrastructure. `everything.get-env` is never
called, because it returns the process environment — it advertises
`readOnlyHint: true`, and is still the one call that must not be captured.

## `fixture/`

**Not committed** — regenerated by `mcp_output.py`, which holds the content as
`FIXTURE_FILES`. Three files the filesystem server is pointed at: invented
addresses under the reserved `.example` domain, a well-known test IBAN, a
reserved-range phone number, and three sentences of ordinary prose so that a
sealing pass has something to find *and* something to leave alone. Nothing here
is real, and nothing here came from a person.

---

Only `name`, `description`, `inputSchema` and `annotations` are kept — the
fields a contract is drafted from. No credentials were used, no server was
asked to do anything, and nothing here was authored by this project: that is
the entire point of the file. What it is and is not evidence of is stated in
[`../mcp_corpus.py`](../mcp_corpus.py) and in
[`../../docs/BENCHMARKS.md`](../../docs/BENCHMARKS.md).
